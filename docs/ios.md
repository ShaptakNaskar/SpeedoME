# iOS build

SpeedoME on iOS is the same app as on Android: every screen, the dials, trips and settings live in
`shared/` (Kotlin Multiplatform + Compose Multiplatform), with the engine in `engine/` and the dials
in `gauges/`. Only the platform pieces differ:

| | Android (`androidMain`) | iOS (`iosMain`) |
|---|---|---|
| GPS | LocationManager GPS provider, foreground service while recording | CoreLocation; background location (blue pill) while recording |
| Steps | step counter / detector sensors | CMPedometer |
| Heading, G-force | rotation vector, gyro, linear acceleration | CoreMotion device motion (north reference) |
| Speed-limit buzz | vibrator waveform, alarm usage (works screen-off) | haptics (only while on screen) |
| Maps | MapLibre Android | maplibre-compose (the same 38 world styles and dark trip maps) |
| Trips / settings | Room + DataStore in app storage | Room (bundled SQLite) + DataStore in Documents |
| Sharing GPX | share chooser, save-as picker | share sheet (includes Save to Files) |
| Nerd page | satellites, NMEA | no satellites/NMEA (iOS doesn't expose them) |
| Background reliability screen | yes (OEM battery settings) | not needed |

`ios/` is just the entry point (`MainViewController`) and the Linux preview; `iosApp/` is the
SwiftUI host, generated by XcodeGen from `iosApp/project.yml`.

## Working without a Mac

- **Compile check on Linux:** `./gradlew :shared:compileKotlinIosArm64 :ios:compileKotlinIosArm64`.
  Linking the framework and building the app need macOS.
- **See the screens on Linux:** `./gradlew :ios:shots` runs the shared app on the desktop with the
  engine's simulator, records a short trip and writes PNGs of every screen at the iPhone's 3x scale
  to `ios/build/shots` (no display needed). `./gradlew :ios:preview` opens it in an iPhone-sized
  window. Desktop fonts stand in for San Francisco and maps show the plain route drawing.
- **Build:** version tags (`v*`) run the single `.github/workflows/ios.yml` release workflow on GitHub's
  macOS runner. Pushing `main` does not start another build. Manual builds remain available from Actions. Xcode calls Gradle
  (`:ios:embedAndSignAppleFrameworkForXcode`), which also bundles the Compose resources (gauge fonts).
  The run keeps an IPA artifact (`gh run download --name SpeedoME-ios-unsigned`). On a version tag, it also attaches the versioned IPA to the draft release and publishes only when the signed APK is present.
- **Sign and install:** with your certificate (zsign on Linux, or ESign on the phone). The app needs
  no special entitlements; background location and motion are Info.plist settings.
  ESign tip: if an install hangs, the phone log shows a timeout on `127.0.0.1:9800/app.ipa` (ESign's
  own server): reopen ESign and stay in it until the install finishes.
- **Logs from Linux:** `idevicesyslog` (libimobiledevice) with the phone on USB; pipe through
  `grep --line-buffered`. Crash reports: `idevicecrashreport`.
