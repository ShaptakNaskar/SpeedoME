# SpeedoME 1.0.1

- Set an arrive-by time with the native iOS time picker, fixing the squashed clock layout when the distance keyboard opens.

## Downloads

- **SpeedoME-1.0.1.apk:** signed universal Android release build, Android 8.0+.
- **SpeedoME-1.0.1-unsigned.ipa:** iOS 16.0+; requires signing with your own certificate before installation. See the [iOS guide](https://github.com/ShaptakNaskar/SpeedoME/blob/v1.0.1/docs/ios.md).

Includes the features and [Waypoint acknowledgements](https://github.com/ShaptakNaskar/SpeedoME/blob/v1.0.1/ACKNOWLEDGEMENTS.md) from [1.0.0](https://github.com/ShaptakNaskar/SpeedoME/releases/tag/v1.0.0).
