# SpeedoME 1.0.2

- Fix the map showing through the native time picker in the iPhone Target dialog.

## Downloads

- **SpeedoME-1.0.2.apk:** signed universal Android release build, Android 8.0+.
- **SpeedoME-1.0.2-unsigned.ipa:** iOS 16.0+; requires signing with your own certificate before installation. See the [iOS guide](https://github.com/ShaptakNaskar/SpeedoME/blob/v1.0.2/docs/ios.md).

Includes the features and [Waypoint acknowledgements](https://github.com/ShaptakNaskar/SpeedoME/blob/v1.0.2/ACKNOWLEDGEMENTS.md) from [1.0.0](https://github.com/ShaptakNaskar/SpeedoME/releases/tag/v1.0.0).
